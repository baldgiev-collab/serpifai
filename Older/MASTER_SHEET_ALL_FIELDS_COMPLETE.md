## 📊 DATA FLOW

### Save Project
```
User fills form (81 fields)
    ↓
collectFormData() → returns object with 81 keys
    ↓
saveProjectDual(projectName, projectData)
    ↓
saveProjectToMasterSheet()
    ↓
Expands 81 fields into 97 columns:
    - Column 1-8: Metadata (name, dates, progress, status)
    - Column 9-26: Stage 1 fields
    - Column 27-36: Stage 2 fields
    - Column 37-46: Stage 3 fields
    - Column 47-49: Stage 4 fields
    - Column 50-81: Stage 5 fields
    - Column 82-96: QA/Legacy fields
    - Column 97: Full JSON backup
    ↓
Writes row to User_Projects tab
    ↓
✅ All 81 fields visible and editable in sheet
```

### Load Project
```
User selects project from dropdown
    ↓
loadProjectFromMasterSheet(projectName)
    ↓
Finds project row in User_Projects tab
    ↓
Reads all 97 columns
    ↓
Tries to parse JSON backup (column 97)
    ↓
If JSON parse fails:
    Reconstructs object from columns 1-96
    Maps: brandIdeology = row[8], brandArchetype = row[9], etc.
    ↓
Returns complete projectData object
    ↓
fillFormData(projectData)
    ↓
✅ All 81 fields populate in UI
```
