## 🐛 Troubleshooting

**Issue: Fonts look basic (Arial/Helvetica)**
→ Wait 5-10 seconds, refresh page (Google Fonts loading)

**Issue: Charts show gray placeholder**
→ Open DevTools Console, check for Chart.js errors
→ Try different browser (Chrome recommended)

**Issue: Tabs don't switch**
→ Console: `typeof window.switchCategoryTab` should be "function"
→ Clear cache, hard refresh (Ctrl+Shift+R)

**Issue: No animations**
→ Check browser supports CSS animations (Chrome 90+)
→ Disable "Reduce Motion" in OS settings
