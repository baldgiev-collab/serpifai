🚀 Quick Start
How do I start my first analysis?
1. Go to Serpifai → Configure API Keys and add your API keys
2. Open Serpifai → Launch Dashboard
3. Click New Analysis and enter your domain + competitors
4. Wait for the 450-keyword forensic analysis to complete
What APIs do I need?
At minimum: Serper.dev for SERP data. Optional: Gemini (AI analysis), PageSpeed Insights, OpenPageRank for enhanced intelligence.
🔑 API Reference
  • Serper.dev
    SERP data, AI Overview detection, featured snippets. Get key at serper.dev
  • Google Gemini
    AI-powered keyword clustering, competitor analysis. Free tier available.
  • PageSpeed Insights
    Core Web Vitals, performance scoring. Free with Google API key.
  • OpenPageRank
    Domain authority metrics. Free tier: 10 domains/request.

❓ FAQ
Why 450 keywords?
Our forensic analysis covers 9 modules × 50 keywords each = 450 total keywords. This provides comprehensive coverage of intent patterns, competitor gaps, and AI Overview opportunities.
How long does analysis take?
Typically 8-15 minutes depending on API response times. Progress is shown in the dashboard.
Where is my data stored?
All data stays in your Google Sheet. API keys are stored in PropertiesService (encrypted by Google).
