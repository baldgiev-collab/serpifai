## 🔴 ISSUE 1: COMPETITOR DATA - "No competitor data available"

### Data Flow Analysis:
```
API Response → window._lastStage1Json → extractCompetitorData() → renderCompetitorForensics()
```

### extractCompetitorData() checks these paths IN ORDER:
1. `window._competitorAnalysisData?.competitorsArray` - Competitive Intelligence tab cache
2. `window._competitorInsights?.authorityMetrics` - Workflow MySQL data
3. `charts?.competitorAnalysis` - Legacy competitorAnalysis array
4. `charts?.competitorKillMovesChart` - V7.12+ kill moves format
5. `json?.competitiveGaps?.competitors` - V7 structure
6. `charts?.competitorPositioning` - Position data
7. `json?.competitorAnalysisSummary` - Summary with topCompetitor
8. `json?.strategicIntelligence?.competitors` - Strategic intel
9. Pattern matching from content text (fallback)
10. `charts?.competitorKillMovesChart` (final fallback)

### ROOT CAUSE:
The function returns EMPTY ARRAY because:
- None of the global caches (`window._competitorAnalysisData`, `window._competitorInsights`) are populated
- The `dashboardCharts` object likely doesn't contain the expected keys
- The data may be at a different path in the JSON structure

## 🔴 ISSUE 2: CHARTS NOT VISIBLE

### Chart Rendering Flow:
```
generateStage1Charts() → creates canvases in #stage1-chart-storage → 
injectChartsIntoCommandCanvas() → MOVES canvases to .chart-wrapper containers
```

### Key Components:
1. **stage1-chart-storage** - Hidden div (`display:none`) where charts are initially rendered
2. **chart-stage-{N}** - Container for each section's interactive stage
3. **chart-wrapper** - Inner container that receives the moved canvas

### ROOT CAUSES IDENTIFIED:
1. **CSS `height: 100%`** on `.chart-wrapper` collapses to 0 if parent has no explicit height
2. **Canvas `height: auto`** after move causes Chart.js to not know rendering dimensions
3. **Parent containers** may have `overflow: hidden` cutting off content
4. **Chart.js resize()** not being called after canvas is moved to new DOM position

### FIX APPLIED (V10.5-10.6):
```css
/* .chart-wrapper */
height: 400px !important;
min-height: 400px !important;
max-height: 500px;

/* Canvas inside */
height: 400px !important;
display: block !important;
visibility: visible !important;
```
